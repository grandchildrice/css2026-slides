# BWS2026 発表準備資料

## 会場と聞き手

- **会場**: CSS2026 / BWS（ブロックチェーンワークショップ）— CSEC 研究会内の委員会
- **聞き手**: ブロックチェーンをサイバー攻撃対策・暗号技術の両面から研究する企業・学術の混在層。ブロックチェーン自体は知っているが、Ethereum コンセンサス（FFG・確定・justification_bits）の詳細に詳しいとは限らない
- **該当トピックス**: コンセンサスアルゴリズム／スマートコントラクトと脆弱性評価／ブロックチェーンデータセット（ethereum-vuln-dataset の参照箇所）

→ Ethereum の基礎から入る構成（スライド2–6）はこの聴衆層に合う。「監査者・実装者に何が届くか」の実務的着地（スライド12・19–21）は企業側の聴衆向けに効く。
